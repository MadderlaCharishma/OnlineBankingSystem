# OnlineBankingSystem
A full-stack Bank Management System developed using Flask and MySQL that simulates real-world banking operations such as user registration, login, deposits, withdrawals, fund transfers, and an admin dashboard for managing accounts and monitoring transactions.
## 🧩 System Architecture

Frontend (HTML/CSS/JS)
        ↓
Flask Backend (Python)
        ↓
MySQL Database

## ⚙️ Features

### 👤 User Features
- Secure registration and login system
- Deposit money into account
- Withdraw funds with balance validation
- Transfer money between accounts
- View transaction history with timestamps

### 🛠️ Admin Features
- Dashboard showing total users and accounts
- View and manage all transactions
- Block or delete user accounts
- Monitor total bank balance in system
